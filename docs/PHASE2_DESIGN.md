# SHARE-LIVE Phase 2 设计方案

## 设计理念

### 视觉风格参考
- **小红书**: 精致卡片、柔和配色、沉浸式浏览
- **Instagram**: 简洁线条、Stories 体验、Reels 全屏
- **Pinterest**: 瀑布流发现、视觉优先
- **BeReal**: 真实感、反滤镜、亲密社交
- **Locket Widget**: 私密分享、小圈子

### 核心设计语言
- **玻璃拟态 (Glassmorphism)**: 半透明毛玻璃效果
- **微交互动画**: 悬停、点击反馈
- **渐变色系**: 紫→粉→蓝的活力渐变
- **圆角美学**: 大圆角卡片和按钮

### 模块二：故事动态 (Stories)

**功能描述:**
24小时限时动态，顶部横条展示好友最新故事

**UI设计:**
```
┌─────────────────────────────────────┐
│ 👤 ⭕ 👤 ⭕ 👤 ⭕ 👤 ⭕          │  ← Stories 横向滚动条
│   ━━                                │     未读有彩色边框
├─────────────────────────────────────┤
│                                     │
│         主 Feed 内容                │
│                                     │
└─────────────────────────────────────┘
```

**交互细节:**
- 点击头像展开全屏故事
- 左右滑动切换不同用户
- 长按暂停，上滑查看更多
- 发布入口：相机图标 + "添加故事"

**技术要点:**
- 图片/视频压缩上传
- 24小时自动过期清理
- 已读状态追踪

### 模块三：话题社区 (Topics)

**功能描述:**
围绕特定话题的聚合页面，类似微博超话/小红书话题

**页面结构:**
1. **话题头图** - 可自定义封面
2. **话题统计** - 参与人数、帖子数、今日新增
3. **管理员/主持人** - 话题维护者
4. **内容 Tab** - 热门/最新/精华
5. **相关话题推荐**

**UI亮点:**
- 话题头图视差滚动效果
- 参与按钮脉冲动画
- 话题徽章系统

### 模块四：通知中心 (Notifications)

**通知类型:**
| 类型 | 触发条件 | 优先级 |
|------|---------|--------|
| 点赞 | 有人赞了你的帖子 | 低 |
| 评论 | 有人评论了你 | 中 |
| 回复 | 有人回复了你的评论 | 高 |
| 关注 | 有人关注了你 | 低 |
| @提及 | 有人在内容中提到你 | 高 |
| 系统 | 官方消息、活动通知 | 中 |

**UI设计:**
- 红点角标显示未读数
- 分组展示（今天/本周/更早）
- 一键已读功能
- 通知设置（可关闭某类通知）

## 动画与交互规范

### 通用动画时长
| 场景 | 时长 | 缓动函数 |
|------|------|---------|
| 页面切换 | 300ms | ease-out |
| 悬停效果 | 200ms | ease-in-out |
| 弹窗出现 | 250ms | spring(1, 100, 10) |
| 加载骨架 | 1500ms | pulse |

### Framer Motion 常用模式
```tsx
// 入场动画
initial={{ opacity: 0, y: 20 }}
animate={{ opacity: 1, y: 0 }}
transition={{ duration: 0.3 }}

// 悬停效果
whileHover={{ scale: 1.02, y: -4 }}
whileTap={{ scale: 0.98 }}

// 列表 stagger
variants={{
  hidden: { opacity: 0 },
  show: { opacity: 1, transition: { staggerChildren: 0.05 } }
}}
```
